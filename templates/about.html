About AgroVision AI

Mini project for plant disease detection and remedy suggestions.

Project Overview

AgroVision AI is an academic mini project designed to demonstrate how Artificial Intelligence can assist in detecting plant diseases using leaf images.

The system predicts the disease, shows severity, and provides basic guidance on symptoms, management and example remedies.

Technologies Used

  • Python – core programming language
  • TensorFlow / Keras – to load the CNN model
  • Flask – backend web framework
  • HTML, CSS, JavaScript – for responsive UI
  • PlantVillage dataset – for training the original model

Key Features

  • Automated plant disease classification using images
  • Confidence and severity indication for each prediction
  • Readable description, symptoms and management suggestions
  • Sample tonic / fungicide suggestions with e-commerce links
  • Modern, animated and user-friendly web interface

Disclaimer

This system is for learning and demonstration only. It is not a medical or agricultural authority. Farmers should always consult agriculture experts or plant pathologists before applying any chemical treatment.
