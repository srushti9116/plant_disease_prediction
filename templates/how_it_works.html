How AgroVision AI Works

Step-by-step explanation of the plant disease prediction pipeline.

1. Image Input

The user uploads a leaf image from the web interface. The system works best when:

  • Only one leaf is visible in the image
  • Background is simple (plain or soil)
  • The leaf is clear and in focus

2. Preprocessing

Inside the Flask backend, the image is:

  • Resized to the required input size (e.g., 224 × 224 pixels)
  • Converted into a numeric array
  • Normalized (pixel values scaled between 0 and 1)

3. CNN Prediction

A pre-trained Convolutional Neural Network (CNN) model is loaded from plant_disease_model.h5. The model:

  • Extracts visual features like spots, color changes and patterns
  • Classifies the image into one of the known disease categories
  • Outputs probabilities for each class

4. Interpretation

The predicted class index is mapped to a readable label such as "Tomato – Early blight" or "Potato – Late blight". The system also calculates a confidence percentage and a severity level.

5. Remedies & E-commerce

Based on the disease, AgroVision AI:

  • Shows description, typical symptoms and management tips
  • Lists sample remedies or tonics with images
  • Provides buttons that open Amazon / Flipkart search pages for related products

Note: Product links are example search URLs. The system does not sell products directly.
